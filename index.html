Getting started

Up and running in two minutes.

01

Download the .dmg

Open it and drag Telebot AI into Applications. The build isn't notarized yet, so if macOS shows a warning, right-click (Control-click) the app and choose Open — once, and it launches normally from then on.

02

Create your bot

Message @BotFather on Telegram, get a token, and paste it into the settings window. One token per bot — run as many as you like.

03

Connect a brain

Point it at mlx-serve, Ollama, LM Studio — or any API provider. Add fallbacks and the bot keeps talking even if one model goes down. New to local models? Read the guide.

FAQ

Answers before you ask.

Do I need an API key or subscription?

No. Run a local model (mlx-serve, Ollama, LM Studio) and everything is free. Data sources — weather, currency, Wikipedia, SEC filings — need no keys. Cloud APIs (OpenAI, Anthropic, Groq, OpenRouter…) are optional and bring-your-own.

Which models can I use?

Anything that speaks OpenAI-compatible HTTP — from tiny local models on your Mac to frontier cloud models like OpenAI and Anthropic Claude. The settings app lets you add fallback providers, so the bot keeps answering even when one is down.

Does my data leave my Mac?

Your chat history, memories and skills stay in ~/.mlx-serve. The only outbound traffic is the Telegram API itself, whatever model server you choose to point the bot at, and anonymous usage stats.

Do I need a powerful Mac?

The menu bar app itself is tiny. Local models scale with your RAM — a 16 GB M-series Mac runs small models comfortably. No Mac? Point the bot at any cloud API instead.

Does it work on Intel Macs?

Not yet — the current build is Apple Silicon only (M1 or newer). The unified-memory architecture is what lets it run big local models; an Intel build is on the roadmap.

Can I run multiple bots?

Yes. Create a bot per token with @BotFather, add them all in settings, and give each one its own model, personality file and skills.

How do I update the app?

The app checks for new versions automatically — the menu bar item and the Updates page in settings will tell you when a new build is out and link straight to the download. Or grab the latest .dmg from this page and drag it over the old app in Applications. Your settings, bots and memories live outside the app, so they carry over untouched.

Why does macOS warn about the app?

Because the build isn't notarized by Apple yet — that costs money and requires a paid developer account. The warning is expected: right-click (Control-click) the app in Applications, choose Open, then Open again. One time, and it runs normally from then on.

Is it really free?

Yes — free to download and use. No subscriptions, no accounts. You only pay for the model provider you choose, if any.
