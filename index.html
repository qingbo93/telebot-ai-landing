Getting started

Up and running in two minutes.

01

Download the .dmg

Open it, drag Telebot AI into Applications, and launch. First launch of an unsigned build? Right-click → Open.

02

Create your bot

Message @BotFather on Telegram, get a token, and paste it into the settings window. One token per bot — run as many as you like.

03

Connect a brain

Point it at mlx-serve, Ollama, LM Studio — or any API provider. Add fallbacks and the bot keeps talking even if one model goes down.

FAQ

Questions, answered.

Do I need an API key or subscription?

No. Run a local model (mlx-serve, Ollama, LM Studio) and everything is free. Data sources — weather, currency, Wikipedia, SEC filings — need no keys. Cloud APIs (OpenAI, Groq, OpenRouter…) are optional and bring-your-own.

Which models can I use?

Anything that speaks OpenAI-compatible HTTP — from tiny local models on your Mac to frontier models in the cloud. The settings app lets you add fallback providers, so the bot keeps answering even when one is down.

Does my data leave my Mac?

Your chat history, memories and skills stay in ~/.mlx-serve. The only outbound traffic is the Telegram API itself, plus whatever model server you choose to point the bot at.

Do I need a powerful Mac?

The menu bar app itself is tiny. Local models scale with your RAM — a 16 GB M-series Mac runs small models comfortably. No Mac? Point the bot at any cloud API instead.

Can I run multiple bots?

Yes. Create a bot per token with @BotFather, add them all in settings, and give each one its own model, personality file and skills.

Is it really free?

Yes — MIT licensed and open source. You only pay for the model provider you choose, if any. Source on GitHub.
