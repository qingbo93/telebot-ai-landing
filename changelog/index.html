Changelog

Every release of Telebot AI, in one place.

v1.0.2 Latest
Aug 14, 2026

One-click in-app updates and full Chinese localization.

  • Auto-update inside the app — when a new version is available, the Updates page shows Update Now: it downloads, verifies the DMG, quits, swaps both apps atomically and relaunches you on the new version. No browser, no drag-and-drop.
  • Every surface now speaks Chinese — sidebar, bot pages, defaults, skill cards, the menu bar app and the skills sheet. A language picker in the sidebar switches live, both ways.
  • Per-model usage — the Model page shows how many requests and tokens each model served; each bot page shows its own request/token stats.
  • Menu bar app is now accessory-only — one clean "Telebot AI" icon in the Dock and Cmd-Tab (the settings app), no duplicates.
  • Clicking the Dock or Cmd-Tab icon re-creates the settings window if it was closed.
v1.0.1
Aug 13, 2026

Friendlier errors, clearer update feedback, and an auto-check toggle.

  • If the app ever fails to start, you now get a “Telebot AI couldn't start” dialog with Visit website to report (opens the feedback form), Copy error and Quit — no more cryptic crash dialogs.
  • Check for Updates now shows real feedback: the menu item flips to ✓ Up to date, and the Updates page shows the result in green (orange while checking, with a Download link when a new version is out). The checking state is held long enough to actually see.
  • New Check automatically setting on the Updates page — turn the launch + 24-hour update checks on or off (default on).
  • Updates page tidied up — installed version, status and the check/download buttons now sit together in one clean row instead of divider-separated clutter.
v1.0.0
Aug 12, 2026

The first public release — the bridge between your Telegram bots and any LLM, local or cloud.

  • Menu bar app — start and stop your bots, open settings and quit, all from the menu bar.
  • Multiple bots — one per token, each with its own model, personality and skills.
  • Bring your own brain — mlx-serve, Ollama, LM Studio, vLLM, OpenAI, Anthropic, Groq, OpenRouter — with automatic fallbacks when a provider goes down.
  • 30+ model-driven tools — reminders, weather, stocks, crypto, polls, dice, expenses, habits, bookmarks, RSS feeds, translation, currency, PDF & receipt scanning, memory, digests and briefings.
  • Keyless data sources — weather, currency, Wikipedia, SEC filings — no API keys required.
  • Telegram-native — streaming replies, typing dots, animated dice, native polls, voice notes in and out.
  • Local-first privacy — chat history, memories and skills live in ~/.mlx-serve on your Mac.
  • macOS 13+, Apple Silicon. Unsigned build — right-click → Open on first launch.
